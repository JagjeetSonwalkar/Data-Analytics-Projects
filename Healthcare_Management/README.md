# Healthcare Management Dashboard

## Project Overview

The Healthcare Management Dashboard is an interactive data analytics project developed using Microsoft Power BI. It provides insights into hospital operations, patient information, department performance, staff details, bed occupancy, treatment costs, and patient satisfaction.

The dashboard transforms hospital data into meaningful visual insights, helping users monitor key performance indicators (KPIs), analyze patient trends, and understand different aspects of healthcare management.

## Dashboard Pages

1. **Hospital Summary** – Provides an overview of hospital performance, including patient statistics, staff information, treatment costs, emergency room time, revenue, and bed occupancy.
2. **Patients Summary** – Analyzes patient demographics, admission and discharge information, length of stay, department-wise patient statistics, feedback, and ratings.
3. **Patients Details** – Provides detailed patient-level information, including patient name, age, gender, location, and status.
