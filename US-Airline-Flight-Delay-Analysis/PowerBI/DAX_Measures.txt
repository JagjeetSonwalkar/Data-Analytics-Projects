US Airline Flight Delay Analysis (2015) — DAX Measures
========================================================
Table: Query (pre-aggregated import from MySQL)

Total Flights =
SUM(Query[total_flights])

Total Delayed =
SUM(Query[delayed_flights])

Total Cancelled =
SUM(Query[cancelled_flights])

On Time Flights =
[Total Flights] - [Total Delayed] - [Total Cancelled]

Avg Delay (min) =
AVERAGE(Query[avg_arrival_delay])

% Delayed =
DIVIDE([Total Delayed], [Total Flights], 0) * 100

Cancellation Rate % =
DIVIDE([Total Cancelled], [Total Flights], 0) * 100

Calculated column — Day Name =
SWITCH(Query[DAY_OF_WEEK], 1,"Mon", 2,"Tue", 3,"Wed", 4,"Thu", 5,"Fri", 6,"Sat", 7,"Sun")
(sorted by DAY_OF_WEEK via Column tools -> Sort by column)

Delay Cause table (separate query/table):
Air System Delay, Security Delay, Airline Delay, Late Aircraft Delay, Weather Delay
-- pulled via a second MySQL import (AVG of each delay-cause column,
-- filtered to CANCELLED = 0 AND ARRIVAL_DELAY > 0), then unpivoted in
-- Power Query into two columns: Delay Cause / Avg Minutes.
